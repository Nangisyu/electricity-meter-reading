전기검침 PWA

1. 압축을 풀고 index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png를 GitHub Pages 저장소에 업로드합니다.
2. 기존 저장소에서 운영 중이라면 같은 파일을 덮어쓰세요.
3. 휴대폰에서 사이트를 다시 열거나 새로고침한 뒤 홈 화면에 추가하세요.
4. 최초에는 각 항목의 전월 지침과 당월 지침을 직접 입력합니다. 다음 달부터 이전 달의 당월 지침이 전월 지침으로 자동 연결됩니다.
5. 백업/복원 메뉴에서 JSON 백업, CSV 내보내기를 사용할 수 있습니다.

주의: 검침 데이터는 해당 브라우저/기기에 저장됩니다. 브라우저 데이터를 지우기 전에 백업하세요.
