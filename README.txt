전기검침 PWA - 항목 추가 기능 포함

기능: 46개 기본 항목, 항목 추가/수정/삭제, 위치 수정, 순서 이동, 월별 지침 입력 및 사용량 계산, JSON 백업/복원, CSV 내보내기.

적용: 기존 GitHub Pages 저장소의 index.html과 sw.js를 교체하고 나머지 manifest 및 아이콘도 함께 유지/교체하세요. 모바일에서 업데이트가 늦으면 앱을 완전히 닫았다가 다시 접속하세요.

데이터는 각 기기의 브라우저에 저장됩니다. PC와 휴대폰 사이 자동 동기화는 되지 않으며, 백업 파일을 다른 기기에서 복원해야 합니다.
